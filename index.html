Pasang di Skrin Telefon

Anda boleh menjadikan dashboard ini seperti aplikasi telefon tanpa perlu membuka pelayar web setiap kali:

Untuk Pengguna Android (Chrome):
  1. Buka pautan dashboard di pelayar Google Chrome.
  2. Tekan tiga titik bertindih (⋮) di penjuru atas kanan.
  3. Pilih "Install app" atau "Add to Home screen".
  4. Ikon Kenderaan akan muncul di skrin utama telefon anda!
Untuk Pengguna iPhone / iPad (Safari):
  1. Buka pautan dashboard di pelayar Safari.
  2. Tekan butang Kongsi (Share ) di bahagian bawah.
  3. Skrol ke bawah dan pilih "Add to Home Screen".
  4. Tekan "Add" di penjuru atas kanan.
